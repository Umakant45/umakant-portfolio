# Umakant Kautkar — Portfolio

A modern, responsive job portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — structure and content
- `style.css` — responsive design and animations
- `script.js` — interactions, filtering, reveal animations and navigation
- `assets/resume.pdf` — add your real resume here

## Run locally

Open `index.html` directly in a browser.

## Deploy

Push the folder to GitHub and connect the repository to Netlify. No npm, React or Vite is required.

## Before publishing

1. Add your real `assets/resume.pdf`.
2. Replace `your.email@example.com` with your email.
3. Replace the LinkedIn URL with your actual profile.
4. Review all project links and descriptions.
